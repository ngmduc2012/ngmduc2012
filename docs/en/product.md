# My Dev

My Dev is where I record how I solve problems while building software. I share the context, the implementation, why I chose it and what still needs consideration, so you can compare it with your own project.

**[Explore My Dev](https://wong-coupon.gitbook.io/flutter/)**

## What you will find

* **My Flutter:** Flutter applications, architecture, state management, data integration, testing and operations.
* **My AI:** building AI features and using coding agents in software development.
* **My ReactJS:** React, TypeScript, realtime interfaces, data management, testing and web application delivery.

## How I write

I put the result first, then explain the problem and the steps taken. Background knowledge is kept to what you need to follow the approach; subjects covered in separate articles are linked for further reading.

You can start with a problem you are facing, check the conditions for using the approach and try it in your own project. Its limitations are part of the story, alongside the result.
